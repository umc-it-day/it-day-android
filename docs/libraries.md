# Libraries

Treat the Gradle configuration as the source of truth. A library mentioned in this document is
not installed unless it is present in `android/gradle/libs.versions.toml` and the relevant module's
`build.gradle.kts` file.

## Installed

These libraries are already configured and may be used.

| Purpose | Library | Notes |
| --- | --- | --- |
| Android foundation | AndroidX Core KTX, Lifecycle Runtime KTX | Configured in the app module. |
| UI | Jetpack Compose BOM, Material 3 | Use Compose for new UI. |
| Tests | JUnit 4, AndroidX Test, Espresso, Compose UI Test | Initial unit, instrumentation, and UI test setup. |

## Add in this change

Add and verify these dependencies before using them in application code.

| Purpose | Library | Intended use |
| --- | --- | --- |
| Navigation | Navigation Compose | Screen navigation and bottom navigation. |
| UI state | Lifecycle ViewModel Compose | Connect Compose screens to ViewModels. |
| Async | Kotlin Coroutines, Flow | Asynchronous work and `StateFlow`-based UI state. |
| Network | Retrofit, OkHttp | Server APIs and shared HTTP configuration. |
| Serialization | Kotlin Serialization | JSON and DTO conversion. |
| Image loading | Coil Compose | Remote images in Compose UI. |
| Maps | Kakao Maps SDK | Map rendering for location-based benefits. |
| Location | Play services Location | Current location and coordinate retrieval. |
| Code quality | ktlint, detekt | Formatting and static analysis in local builds and CI. |

## Deferred until implementation

Do not add or use the following libraries yet. Add each one in a separate change when its stated
condition is met. This keeps compatibility failures isolated and avoids unused dependencies.

| Library | Add when |
| --- | --- |
| Hilt, KSP | Implementing dependency injection for the network or repository layers. |
| kotlinx-coroutines-test, MockK | Adding ViewModel or business-logic tests that need them. |
| JaCoCo | Enabling test coverage reports. |
| Firebase | A specific product such as FCM, Crashlytics, or Analytics is approved. |
| Lottie | An approved Lottie animation asset is ready for use. |
| Room | Structured offline data or caching is required. |
| DataStore | Persisting simple values such as login state or user settings. |

Select versions when implementing the relevant change. Use current stable versions that are
compatible with the project's AGP, Kotlin, and Compose versions. Do not downgrade the versions
generated by Android Studio without an explicit compatibility reason.
